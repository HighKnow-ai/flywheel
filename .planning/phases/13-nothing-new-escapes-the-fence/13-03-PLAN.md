## Phase goal

**Goal (ROADMAP, verbatim):** Every structural guarantee the milestone is about to lean on is
closed-world and asserted *before* the first new record type exists — the spine cannot erode, an
unclassified table fails the build, authority is reachable only from a human, the context packet is
bounded, and the fields nobody reads are gone rather than drafted.

> MVP note: the ROADMAP Goal line is not in user-story form and no story was invented. See 13-01.

<objective>
Delete `estimate` — the field nobody reads — from the schema, the domain, the queries and the UI
(DRFT-05, D-14), and deliberately reuse the required table rebuild as the early proof that
`criterion_anchors` rows survive a `tasks` rebuild (D-15), so Phase 16's RECD-04 can cite it
instead of repeating it. F4 narrows with the column: `set_estimate` disappears, and
`set_priority_in_tx` becomes required rather than optional because accepting a priority suggestion
happens inside the proposal-acceptance transaction (D-17).

This plan is the phase's widest vertical slice: migration, domain, query, IPC command, UI, and the
gate that keeps the field from coming back.

Purpose: the fields nobody reads are gone rather than drafted — and FNC-01's spine pin (plan 13-04)
is written against the post-drop schema, so this must land first.
Output: migration 0023, a narrower domain and query surface, a deleted picker, and a source gate.
</objective>
