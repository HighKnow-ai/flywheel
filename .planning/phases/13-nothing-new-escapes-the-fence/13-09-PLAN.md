## Phase goal

**Goal (ROADMAP, verbatim):** Every structural guarantee the milestone is about to lean on is
closed-world and asserted *before* the first new record type exists — the spine cannot erode, an
unclassified table fails the build, authority is reachable only from a human, the context packet is
bounded, and the fields nobody reads are gone rather than drafted.

> MVP note: the ROADMAP Goal line is not in user-story form and no story was invented. See 13-01.

<objective>
Authority becomes reachable only from a human, enforced in two places at once: a database read of
`actors.type` inside the write transaction (the same precedent `start_agent_run` already uses to
refuse the system actor), and a source gate proving no agent-reachable module calls an authority
writer. Both directions are asserted — an agent is refused, a human is not blocked — because round
ten of the Phase 12 gate work passed every offline test it had and still bricked the product by
being right in one direction only.

The three sites that write past the current gate are closed in the same pass: F5's raw status write
is deleted (plan 13-07, A-01), and the two `updated_at` touches in `acceptance_criterion.rs` are
allow-listed with their reason — after the gate is widened so the class they belong to is actually
caught, which is what makes the allow-list mean something.

Purpose: criterion 2 in full, and FNC-03 before the first record type that will need it.
Output: one precondition helper, one two-sided test file, a widened gate, and a committed allow-list.
</objective>
