## Phase goal

**Goal (ROADMAP, verbatim):** Every structural guarantee the milestone is about to lean on is
closed-world and asserted *before* the first new record type exists — the spine cannot erode, an
unclassified table fails the build, authority is reachable only from a human, the context packet is
bounded, and the fields nobody reads are gone rather than drafted.

> MVP note: the ROADMAP Goal line is not in user-story form and no story was invented. See 13-01.

<objective>
F8: the `board:changed` payload is discarded on the renderer side, so every subscriber invalidates on
every event — a change in one project re-fetches an unrelated project's views. The emitters already
carry a partial payload (`{ entity, id }`); what is missing is the project id and a reader that
routes on it.

The lazy correct shape: one typed emit helper in `commands/mod.rs`, every raw emit replaced with it
(a mechanical change across 72 sites in 13 files), one routing decision in
`useBoardChangedSubscription`, and a source gate so the 73rd emit cannot skip the helper.

Purpose: criterion 5's second half, and the structural precondition for the Cycle, PRD and ADR
reader sets arriving in phases 14-18, each of which would otherwise add another always-invalidated
subscriber.
Output: a typed payload, one emit helper, project-routed invalidation, and two-sided gates on both
sides of the seam.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rust core -> the webview, over the Tauri event channel | The payload crosses a process boundary and is parsed by TypeScript that cannot trust its shape |
| one project's mutation -> another project's cached views | The leak FNC-07 closes; today every subscriber sees every project's events |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-47 | Information Disclosure | one project's event waking another project's readers | medium | mitigate | Routing on `projectId` with a zero-`invalidateQueries` assertion for the cross-project case |
| T-13-48 | Denial of Service | a stale board after an unroutable event | high | mitigate | A malformed or null `projectId` broadcasts rather than dropping; a named test covers the malformed shape |
| T-13-49 | Tampering | a 73rd raw emit skipping the helper | high | mitigate | `only_the_emit_helper_names_the_board_changed_event` plus `the_emit_gate_fires_on_a_planted_raw_emit` |
| T-13-50 | Denial of Service | coalescing on an unmeasured event rate losing events | medium | accept | No coalescing is introduced; the rate is recorded as unmeasured in the research round and an acceptance criterion asserts no timer was added. Revisit only with a measurement |
| T-13-51 | Tampering | the adapter seam being bypassed by a second `listen` import | medium | mitigate | An acceptance criterion asserts exactly one module imports the Tauri event API |
| T-13-52 | Tampering | npm/pip/cargo installs | high | accept | No dependency added; `@tauri-apps/api` and `serde_json` are already in the tree |
