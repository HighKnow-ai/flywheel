**The prompt.** Rewrite `render_epic_prompt`'s `## Your Task` block, both the premise and no-premise
branches, to ask for staged adaptive rounds explicitly:
  - one focused question per turn, never a numbered list of several;
  - no pre-supplied default answer beside the question — a default is what turns the exchange into a
    form to tick through, and the todo records that it did;
  - the next question shaped by the developer's last answer, so the exchange develops rather than
    being emitted up front;
  - a challenge raised when it arises, not deferred to a later batch after the developer has
    answered everything — the observed shape put the real challenges in turn 4, which is the half the
    developer judged insufficient;
  - the stage ends when the developer advances it, which they alone can do, so there is no budget of
    questions to spend and no reason to front-load.

Keep the existing branch structure, the existing "no proposal tool exists in this stage" sentences
and the existing three-stage explanation. The register stays factual and the prose stays in the same
voice as `render_planning_prompt`.

**The recorded artifact.** Extend the `challenge -> decompose` `StageInstruction` in
`authoring_session.rs` so it asks the agent to stage one `propose_assumption` per settled answer
from the rounds, carrying the question and the answer in the assumption's own text. That makes the
exchange reviewable per item in the existing `ProposalTray`, exactly the way GSD's own discussion log
is reviewable — and it reuses `propose_assumption`, the proposal tray and the per-item accept/reject
that all already exist. No new record type: D-89's accepted-assumption-is-the-record reasoning
already covers this, and phase 16 owns the PRD and ADR record types.

**What this task deliberately does not do.** It does not make the session *enforce*
one-question-at-a-time structurally (the todo's first open question). Enforcement would mean counting
question marks in a model's prose, which is a brittle gate on a conversational surface and the exact
shape of a rule that gets disabled. The prompt asks; the human advances; the artifact records. If a
future live run shows the prompt alone is not enough, the enforcement argument has evidence behind it
then.
