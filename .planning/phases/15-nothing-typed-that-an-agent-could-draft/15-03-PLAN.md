## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend wire → adapter seam | `rate_limit_event` and assistant-envelope error fields are untrusted, partially-present model-side data |
| adapter seam → `limit_gate` | an already-normalised tier crosses here; the gate names no backend and reads no backend field |
| harness report → owner verdict | the report is the evidence a human signs off on, so a false `observed` is a false sign-off |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-11 | Repudiation | the harness claiming the `Rejected` tier was observed | high | mitigate | `--self-test` asserts the report cannot print `observed` for that clause unless a real-backend tier set it; the constructed path is labelled `constructed` |
| T-15-12 | Spoofing | a malformed wire line yielding a fabricated tier | high | mitigate | `rateLimitTier` matches the top-level status exactly and yields no tier for anything else; `normalise_resets_at` returns `None` for absent/malformed values, pinned by Task 1 |
| T-15-13 | Denial of service | a paused gate with no reset instant stalling all dispatch | medium | accept | Designed behaviour: `DispatchGateLine` says the reset time is unknown and offers Resume now, so the stall is visible and user-clearable rather than silent |
