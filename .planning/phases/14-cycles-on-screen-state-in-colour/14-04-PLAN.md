<objective>
The state vocabulary: five classes defined by meaning, four token roles each, one component that is
their only consumer, and a source gate that fails the build when anything else reaches for them.

This plan ships the vocabulary and its enforcement. It does NOT delete the existing colour
consumers (14-07) and does NOT prove CVD distinguishability, per-mode contrast or forced-colors
behaviour (14-08) — but its values are derived against the AA and 3:1 floors by search rather than
by eye, the way the dark brand lift was, so they are a real value set from the first commit and not
a figure waiting to be filled in. Plan 14-09 tunes them on the demonstration board.

Purpose: VIS-01 in full, and the half of criterion 3 that is a structural rule rather than a
measurement.
Output: a `--state-*` block in both mode blocks of the shipped stylesheet, its typed mirror, two
new legend marks, one component, and a two-sided source gate.
</objective>
