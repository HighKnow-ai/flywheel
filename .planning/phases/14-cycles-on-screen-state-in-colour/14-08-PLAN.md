<objective>
The measurement half of criterion 3: what a person can actually tell apart.

Three obligations, each asserted rather than claimed. Every pair of state colours stays
distinguishable under the three common colour-vision deficiencies. Every text role is measured
against every surface tint it can land on — now including every state wash — in both modes, against
the bytes the product ships. And forced-colors mode keeps every state readable, measured in a real
engine because jsdom has no idea what the system did to the colours.

Nothing here is a new dependency: the CVD matrices are small enough to implement, the contrast
machinery and its byte parser already exist, and Playwright's per-context emulation is already how
the dark and reduced-motion arms work.

Purpose: VIS-03 and VIS-04 in full, and the measured half of criterion 3.
Output: one CVD module and its every-pair test, an extended contrast matrix, a fourth browser arm,
and the measured thresholds written into the direction document.
</objective>

## Edge coverage (spec-less probe fallback)

Phase-wide arithmetic: **24 probe-surfaced edges == 22 authored into `must_haves.truths` + 2
surfaced as flagged assumptions.** This plan authors 7 of the 22 and carries none of the 2 flagged.

**VIS-03**, all three resolved with `verification: explicit`:

- **adjacency** — two state colours that simulate to the same point collide and the pair fails; a
  pair exactly at the floor passes and one step below fails, both asserted with synthetic colours.
- **empty** — a single class forms no pair, so the test pins the pair count against the expected
  count over the enumerated classes and cannot pass vacuously on an empty or truncated set.
- **ordering** — distinguishability is symmetric: each unordered pair is asserted once and the
  verdict does not depend on which colour is named first, asserted directly.

**VIS-04**, all four resolved with `verification: explicit`:

- **adjacency** — a measurement exactly at 4.5:1 passes and one step below fails; the same on both
  sides of 3:1, constructed with the file's existing ratio constructor.
- **empty** — a role declared in one mode's block and absent from the other fails, both ways; the
  per-mode parse compares a mode against its own block only, so the matrix can never be silently
  empty.
- **encoding** — values are compared as lowercase six-digit hex byte strings parsed from the
  stylesheet block; a three-digit, uppercase or functional spelling of the same colour is a drift
  error rather than a match.
- **ordering** — the matrix is iterated over modes, roles and surfaces in declaration order and
  every failure message names mode, role and surface, so the report is stable across runs.
