<objective>
`05-VERIFICATION.md` truth #19 is the only FAILED truth in this phase, and it is a criterion that
cannot report a genuine result — the exact defect class the whole `G-05-2` wave existed to
eliminate, reproduced in the opposite direction. The pre-`G-05-2` defect was a criterion that could
never fail. `CR-01` is a criterion that can almost never pass: on any live run where a proposal is
legitimately created during decompose (D-88's own expected outcome once D-90's human gate opens the
stage), `finalNoWorkPlannedReading` re-scans the entire unscoped event array, sees the decompose
stage's own legitimate `propose_*` calls, finds no challenge-stage refusal answering them, and
forces `"violated"`. SHAPE-01 and SHAPE-02 become mutually exclusive in practice.

This plan closes it at the root rather than at the symptom. The reading's window stops being an
implicit "whole array" default that one call site happens to scope correctly and another happens
not to, and becomes a required parameter — so the unscoped call is unwritable rather than merely
discouraged. Then it proves the fix on the path that matters: a scripted run that challenges
cleanly, advances through D-90's gate, and proposes legitimately during decompose — asserting both
that the bounded reading passes AND that the unbounded one would still have failed, so the
regression cannot rot into a tautology.

Purpose: make SHAPE-01's second half able to report a genuine result in both directions, so the
next live run's verdict is trustworthy rather than spuriously false.
Output: a promoted reading with a required window, a per-attempt refusal correlation, a new offline
replay scenario that reaches decompose legitimately, and three cosmetic review findings cleared.
</objective>
