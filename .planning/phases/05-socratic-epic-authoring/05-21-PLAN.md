<objective>
Plan 05-20 makes the instrument able to hear a whole turn. This plan makes it able to hold a
conversation and to report a criterion that can fail.

Two defects remain from G-05-2, both independent of the capture bug and both separately sufficient
to make a run worthless:

**The conversation is fixed-depth and advances mid-generation.** `uat-08:906-911` fires
`advance-stage` the instant the second chunk lands — while the agent is still generating — and the
script sends exactly one canned follow-up regardless of what was asked. In the 2026-09-24 run the
agent named three things that would materially change what gets built; none was answered; decompose
was then handed `authoring_session.rs:285-294`'s distillation instruction, which asks the agent to
propose each challenged assumption *together with the answer I gave you*. There were no answers to
carry. That is the concrete mechanism behind the 120-second proposal timeout.

**SHAPE-01's second half cannot fail.** `uat-08:874-876` reads `event.name` on `tool_call` events
whose field is `toolName` (`packages/sidecar/src/adapter.ts:51-55`), so `proposeAttempted` is
structurally always false and `criterion1NoWorkPlanned = !proposeAttempted || proposeDenied` is
vacuously true. The transcript's `proposeAttempted: false` line is evidence of nothing. This is the
most corrosive item in the wave: it manufactures a green that means nothing, and fixing only the
field read would leave a criterion that still cannot fail in the common case.

The decisions at stake are locked and unchanged: **D-88** (the proposal tools are structurally absent
during the challenge stage — the challenge is enforced by the gate, never by a prompt) and **D-90**
(the human holds the advance gate; the harness stands in for the human and must therefore behave
like one, which means not advancing mid-sentence).

Purpose: make the instrument's conversation deep enough to reach decompose honestly, and make its
verdict falsifiable.
Output: a responsive, bounded, non-laundering conversation driver; a three-valued no-work-planned
reading pinned to the product's own type declaration; and offline scenarios that prove each of them.
</objective>

<assumption_delta_decision>
**The noun that is now primary:** *an open question* — something the agent asked that the developer
has not yet answered.

**Decision: `promote`.**

`uat-08` modelled the conversation as a fixed script: opening prompt, one canned follow-up, advance.
That model assumes the agent's reply is inert — that nothing in it needs a response. The run it was
built for proved the opposite: the agent asked three questions and the script talked past all three.

So the open question becomes primary, and conversational depth becomes a consequence of the dialogue
rather than a constant in the file. The bound stays (a cap on agent turns, so a runaway conversation
cannot burn credentials indefinitely), but the cap is now an explicit, reported, *escape* condition
with its own closing turn — never the normal path, and never silent.

The promote is enforced: a scenario in which the agent never settles must produce a closing turn that
names the escape, and a scenario in which it settles must produce zero closing turns. Both are proven
by a command that costs nothing.
</assumption_delta_decision>
