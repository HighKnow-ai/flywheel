<objective>
Ask for the criteria. Nothing ever did.

Plan 05-44 makes `propose_criterion` reachable. This plan closes the other half of the same gap,
measured during planning and not named in the gap report's own `missing` list:

- `advance_stage` (`authoring_session.rs:350`) returns a `DistillationInstruction` ONLY when the
  transition lands on `decompose`. Advancing `decompose -> criteria` returns `None`, so entering
  D-88's third stage — the stage literally named `criteria` — delivers the agent nothing at all.
- The one instruction that does get delivered, `DISTILLATION_INSTRUCTION_TEXT` (`:310-315`), asks
  for D-89 assumption rows, one call per assumption, and ends "Go ahead now." It says nothing about
  tasks and nothing about criteria.
- The opening prompt's closing line (`epic_context_packet.rs:529` and `:540`) tells the agent not to
  propose tasks or criteria until the developer advances the stage — correct for `challenge`, and
  never followed by anything that says the moment has arrived.

So in live run `01M3ENQMC3E4M2HP7014MA84PX` the agent did exactly what it was asked: one epic and
twelve assumption rows. `epic: 1, assumption: 12` is not a model failure; it is the instruction set
read literally.

This plan is deliberately narrow about WHICH half it fixes. The agent also gave a second, judgement-
based reason for not staging tasks — they are downstream of twelve assumptions the developer has not
triaged. That reasoning is defensible and this plan does not override it. What it fixes is the
structural half: the agent is told the ids are readable, and the criteria stage finally asks for the
thing it exists for.

Purpose: SHAPE-03 says "the agent drafts acceptance criteria for each generated task". No turn in
the product has ever asked it to.
Output: D-88's third stage gains its own instruction; the second stage gains one sentence about
where an id comes from; the type that carries both is named for what it is.

The round's end-to-end tracer is plan 05-44 Task 2; this plan expands out from that proven slice and
adds no second vertical path.
</objective>
