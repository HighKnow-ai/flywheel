<objective>
Bash brace expansion is a real, unconditional word-formation mechanism that C1 (quote and backslash
removal) and C3 (`$`, backtick, letter-adjacent glob) do not model at all. `grep` confirms the string
`brace` appears zero times in `docs/destructive-gate-trust-boundary.md`. This plan names it in the
document first, then teaches C3 to see it, then narrows the two claims the finding proved unsound.

The finding is stronger than the code review and the verifier were able to establish. Both reported
they could not construct a brace obfuscation of one of the six shadow keywords, because a
`,`-separated brace group produces two or more words. Measured live during this planning pass, with
harmless `echo` payloads only (D-63): `al{i,}as` expands to the two words `alias alas` — the REAL
keyword FIRST — and because `alias` accepts multiple `NAME` / `NAME=VALUE` arguments and errors
harmlessly on the junk one, `al{i,}as gitx="echo BRACE_ALIAS_FIRED"` under `shopt -s expand_aliases`
genuinely defines the alias. So brace expansion CAN assemble a shadow keyword. The classifier reports
`sh -c 'al{i,}as git=/usr/bin/git; git push --force'` as
`{"category":"safe","namesGatedProgram":true,"textCanShadowPathResolution":false}` today, so the hook
defers.

The claim is deliberately bounded: a plain non-interactive `sh -c`/`bash -c` has `expand_aliases`
off by default, so the construct only fires when the command text also enables it — and
`shopt -s expand_aliases` itself trips no keyword scan, because `raw_text_contains_word` requires a
non-identifier boundary and the character before `alias` in `expand_aliases` is `_`.

Purpose: the document's own rule for round six — a newly found bypass shape is a boundary failure;
amend the document first, only then a corpus row — is binding, and it has not been honoured for this
finding. Plan 03-34 adds the corpus rows and depends on this plan for exactly that reason.

Output: a trust-boundary document that names brace expansion, rules on WR-03, and states the class
for which `text_names_gated_program`'s negative is sound; and a C3 that reports indeterminacy for
brace-adjacent text instead of a confident `false`.
</objective>
