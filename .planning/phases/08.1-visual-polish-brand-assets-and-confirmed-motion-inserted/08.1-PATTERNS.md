### `C/src/query/filter.rs` - add `has_worktree` (model, CRUD)

**Analog:** itself. The full blast radius (RESEARCH Pattern 7) is: `BoardFilter`, `FilterBinding`, `apply_filter`, `FILTER_WHERE` here; six `named_params!` sites binding `":estimate_json"` (`C/src/query/mod.rs:283,327,402`; `C/src/query/search.rs:189,235,309`); `BoardFilterInput` + its `From` impl (`D/src-tauri/src/commands/board.rs:133-145`); `toFilterInput` in `useBoardQuery.ts`; `BoardFilterDraft`/`EMPTY_FILTER_DRAFT` in `state/uiStore.ts`; `FilterBar.tsx`.

**Binding pattern** (`filter.rs:48-67, 90-100`): every dimension is an `Option` mapped to a JSON string or `NULL`.
```rust
pub struct BoardFilter { pub statuses: Option<Vec<String>>, /* ... */ pub estimates: Option<Vec<i64>> }
pub struct FilterBinding { pub status_json: Option<String>, /* ... */ pub estimate_json: Option<String> }
// in apply_filter:
estimate_json: filter.estimates.as_ref().map(|v| to_json(v)),
```
**Fragment pattern** (`filter.rs:107-114`) - stays a compile-time `concat!` literal (T-01-23; `core/tests/epic_context_packet.rs:751` allow-lists `FILTER_WHERE` by name):
```rust
pub const FILTER_WHERE: &str = concat!(
    "(:status_json IS NULL OR b.status IN (SELECT value FROM json_each(:status_json)))",
    /* ... */
    " AND (:estimate_json IS NULL OR COALESCE(b.estimate, 0) IN (SELECT value FROM json_each(:estimate_json)))",

```
New clause, per RESEARCH: `AND (:has_worktree IS NULL OR EXISTS (SELECT 1 FROM worktrees w WHERE w.task_id = b.id AND w.status = 'active'))`. A boolean bound as a named parameter, never interpolated. Epic rows (`b.kind = 'epic'`) have no worktree: epic semantics is a `checkpoint:decision` (RESEARCH A9), do not decide it in a task.
**Bind site pattern** (`query/mod.rs:283`): `":estimate_json": binding.estimate_json,` inside `named_params!`. Add the new bind to all six sites or one query silently errors.

## Shared Patterns

### One query per board, invalidated on `board:changed`
**Source:** `useBoardQuery.ts:1058-1084` (`useForgeFlags`). **Apply to:** `useChangeFlags`, `useEpicProgress`. Never a per-row or per-epic `useQuery`.

### Derive at read time, never cache a verdict (D-75)
