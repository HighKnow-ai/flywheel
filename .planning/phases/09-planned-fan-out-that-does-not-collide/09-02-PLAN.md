<objective>
**Phase goal (ROADMAP `**Goal**`, verbatim — it is not in `As a / I want to / so that` form):** Cyril turns
one epic into several agents working at once, with parallelism bounded by real file-set disjointness rather
than optimism.

The tracer proved the refusal. This plan makes the refusal **visible on the board**: the hook's denial
becomes a `task.scope_denied` event, and a close-time detective backstop catches the writes the file-tool
matcher structurally cannot see.

Purpose: PLAN-05 forbids a silent block. A refusal that exists only in a transcript the user is not
watching — and under fan-out they are watching none of them — is a silent block. Notice delivery is best
effort, so the backstop is not optional polish: it is the half that makes "no refusal is silent" a claim
rather than a hope.

Output: the `scope_denied` notice kind end to end, the `task.scope_denied` event, the per-task count query,
and `scope_backstop_findings` wired into session close.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook process → permission socket | A notice is unauthenticated on a per-run socket; its contents must not be trusted for identity. |
| sidecar → Rust reader | Event lines cross a process boundary and reach a database write. |
| agent process → scope marker file | The agent can reach its own runtime directory through a shell. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-02-01 | Spoofing | notice body identity field | high | mitigate | The event's run identity is taken from the adapter's session closure; the notice body's identity is not read |
| T-09-02-02 | Repudiation | a lost notice hides a refusal | high | mitigate | Close-time backstop raises the same event from git state, so delivery is not the only path |
| T-09-02-03 | Tampering | agent rewrites its own scope marker | medium | mitigate | The backstop compares against the database rows, never the marker, so marker tampering does not suppress detection |
| T-09-02-04 | Denial of service | a looping agent floods the event log | low | accept | Rows are small and the aggregate is indexed; D-154 forbids coalescing and forbids stopping the run — the count is the signal and the user decides |
| T-09-02-05 | Information disclosure | a path in an event payload crosses to the renderer | low | mitigate | Paths stored repository-relative; the handler maps core errors through the existing fixed-category error mapper so no absolute filesystem path crosses IPC |
| T-09-02-06 | Tampering | writes through `Bash` are not prevented | high | accept | Structurally outside the file-tool matcher; detected at close, named as a residual in this plan's own artifacts and in the phase SUMMARY |
</threat_model>
