<objective>
Close gap G-02-2 (`02-UAT.md`, blocker, test 1). `buildClaudeArgv` omitted the flag the real CLI
requires alongside `-p` and the stream-json output format. The CLI rejected the combination at
argument validation, exited 1 having emitted nothing on stdout, and wrote the reason to stderr —
which this adapter never reads. The user saw a session that closed instantly with a bare
`session_closed: failed` and exactly one line in its persisted log.

The argv half is already patched in the working tree and verified against claude 2.1.236. **This plan
owns committing that patch** — it is deliberately uncommitted so the commit lands on this plan's
ledger rather than on verify-work's. A second confirmation was captured during planning: the patched
argv shape runs the real CLI through to a clean terminal result line.

Purpose: the argv was one bug; the reason it took a blind debugging session to find is the real one.
The child is spawned with a default stdio configuration, so its stderr is a pipe nobody reads — both
a discarded diagnosis and a latent blocking hazard once a child writes more than the pipe buffer
holds. The terminal event carries only the word `failed`, so a bad argv, a missing binary and an auth
failure all present identically and undiagnosably. That will happen again for the next failure unless
the channel exists.

And the reason the argv shipped broken at all is the third cause worth naming: the unit test asserted
`buildClaudeArgv`'s output as an exact array literal, so it locked the rejected command line in as
ground truth, and nothing in the suite ever ran the real binary — `test/fake-claude.mjs` validates no
arguments at all. Twenty-nine tests passed on an argv the CLI always rejects.

**Correction to record in the SUMMARY:** `02-RESEARCH.md` § "Agent Adapter Interface" states the
flag need only be added "if token-level deltas are wanted — not required for D-32's row-per-event
feed". That is empirically wrong for the print-mode stream-json combination and is the research error
this gap traces back to. Record the correction in the SUMMARY; do not rewrite `02-RESEARCH.md`, which
is a dated record of what was believed at the time.

Output: the argv fix committed behind a constraint-shaped guard, a drained child stderr routed into
the event stream and onto the terminal event, a failure reason visible in the session surface, and a
real-binary test with a companion that proves it can fail.
</objective>
