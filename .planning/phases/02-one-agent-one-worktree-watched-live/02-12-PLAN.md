<objective>
Close gap 2 of 4 (`02-VERIFICATION.md`, CR-03 in `02-REVIEW.md`): the single shared
`while let Some(event) = rx.recv().await` loop in `spawn_sidecar` — the only place any sidecar stdout
line is read, for every run — opens each run's session log with a panicking call. One run's
unwritable log file therefore terminates the only reader task in the application, silently (stderr is
suppressed on release Windows builds), and from that moment no event for any run is written or emitted
for the rest of the app session. That is a provable violation of `02-07-PLAN`'s own stated prohibition.

**MVP framing note:** `MVP_MODE` is enabled, but the ROADMAP Phase 2 `**Goal:**` line is not in
`As a … I want to … so that …` user-story format, so the MVP user-story enrichment is deliberately
NOT invented here. Run `/gsd mvp-phase 02` if the story framing is wanted on the roadmap entry.

Purpose: the fix is not merely "do not crash". `02-07`'s prohibition says output is never *silently*
dropped — so a skipped write must become visible to the user, and the run must be retried rather than
permanently written off.
Output: a per-run persist seam that cannot panic, a reader loop that survives every per-run fault, a
visible incomplete-transcript banner, and a real test that forces one run's log open to fail and
proves another run's events keep flowing.
</objective>
