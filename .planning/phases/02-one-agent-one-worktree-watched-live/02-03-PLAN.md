<objective>
Expansion slice: the shared signal vocabulary every remaining Phase 2 surface binds to — four colour
roles, six marks on a new `agent` channel, and eight keyboard actions.

Purpose: this phase introduces five new states a user has to read at a glance (running, blocked,
completed, failed, interrupted) plus a blocked count on the project rail. Phase 1's house rules are
that no mark may exist the legend does not define, that meaning never rests on colour alone, and
that `state/keyboard.ts` is the only place a key maps to an action. Establishing the vocabulary once,
before the four surfaces that consume it, is what stops each of those surfaces inventing its own.

This plan runs in parallel with 02-02 and shares no file with it.

Output: `tokens.css` / `tokens.ts` colour roles with asserted contrast, the `agent` mark channel,
and the new `ActionId` members and bindings.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keystroke → action dispatch | A resolved action id is what the rest of the app acts on; a binding that resolves in the wrong region would grant a capability the current surface should not expose. |
| design token → rendered surface | A colour role used on the wrong material family produces an unreadable signal, which for the blocked state means an agent sits blocked and unnoticed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-15 | Elevation of Privilege | permission-answer bindings leaking outside the card's focus region | high | mitigate | `bindingAllowedInLayer` permits `answer-permission-*` only in the permission-card layer, and a test asserts `a` in `board-list` still resolves to the assignee picker while `a` in `permission-card` resolves to Allow — so a stray keystroke on the board can never approve a tool call. |
| T-02-16 | Tampering | Escape dismissing a pending permission card | high | mitigate | The card is excluded from the `EscapeLayer` ladder entirely and no Escape handler is added to the card, so no key path resolves a pending request without an explicit answer. |
| T-02-17 | Information Disclosure | a blocked signal rendered as colour alone and missed by a colour-blind user | medium | mitigate | Every agent-channel mark carries a non-empty glyph and a non-empty label, asserted by the legend test; the blocked pill renders `ShieldAlert` plus the word "Blocked". |
| T-02-18 | Denial of Service | an unreadable blocked pill on a strip tint leaving an agent unnoticed | medium | mitigate | `--blocked-text-strip` is asserted at 4.5:1 or better against all five workflow tints individually, not against a representative swatch. |
</threat_model>
