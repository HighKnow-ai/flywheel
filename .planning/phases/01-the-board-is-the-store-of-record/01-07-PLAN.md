<objective>
Give the rack an unambiguous answer to "what is next": a priority field that sorts first, a manual
fractional rank that orders within a priority band, a coarse nullable size, and an assignee — all
set from the keyboard, all filterable, and each reorder rewriting exactly one row.

Purpose: `BOARD-05` is a requirement, but the deeper reason is that an agent reading this board in
Phase 9 needs one deterministic answer to what to pick up next. Two items that compare equal would
make the planner's choice arbitrary, so the sort has to be total.

Output: reordering that stays O(1) per move at 1,000 items, and a total order the board reproduces
on every read.
</objective>
