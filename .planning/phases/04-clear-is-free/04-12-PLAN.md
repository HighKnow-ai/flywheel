<objective>
**As a** developer running agents unattended, **I want to** find out from the board that a session's
claims and the repository disagree, **so that** I am told rather than left to discover it in the diff.

D-74 settles both halves: the warning goes in the packet so the *agent* reads it too — plan 04-11 did
that — and it simultaneously raises the needs-you signal Phase 2 already built, so a run nobody is
watching cannot drift with nothing on the board ever saying so. And it blocks nothing. D-46 settled the
blocking question for this whole product: only money burning blocks, and drift is not money burning.

Purpose: give the fired detector a durable, human-renderable trail and a board-visible state, without
building a new surface or a new lifecycle.

**Planner call, resolving CONTEXT.md's open item on whether a fired detector is acknowledgeable: it is
not.** There is no acknowledge button and no dismiss action. D-75 already says the warning clears when
the underlying fact clears, and this plan makes that literal — the needs-you set reads the drift events
of each task's *most recent* run, so once the fact is gone the next run records none and the task drops
out by itself. That keeps the rail count from becoming permanently non-zero without inventing a
lifecycle, which is exactly what D-75 rejected a first-class drift-findings table for.

**Planner call, resolving where the board signal lives.** Drift joins the **existing** needs-you signal
as a third contributing fact, alongside D-45's missing worktree and D-49's unacknowledged abandoned run
— not as a fourth badge. `query/recovery.rs`'s own module comment already enumerates the two facts that
make an item outstanding; adding a third to that same union gives D-74's board-visible state and its
rail count with zero new UI, and it is the honest reading of D-46's "everything else is a persistent
needs-you item".
</objective>

| agent-authored warning text → activity trail | The sentence naming a contradiction is stored and rendered to the developer; it must be the same string the agent was shown, not a re-composition. |
