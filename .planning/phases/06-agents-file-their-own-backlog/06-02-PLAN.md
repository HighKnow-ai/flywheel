<objective>
**As a** developer, **I want to** be shown that no code path anywhere can turn an agent's proposal
into real work without me, **so that** I can leave agents proposing unattended without auditing the
queue for things that promoted themselves.

`ROADMAP.md`'s own Phase 6 note is explicit: criterion 1 must be verified by proving no promotion path
exists, not just that the happy path asks first. D-100 says that closes on two halves — a source
gate and an adversarial corpus — and that neither suffices alone. This plan builds both, in one
new self-contained test file, and adds the source-level assertion that `domain::issue`'s own header
comment already claims but nothing checks today.

Purpose: turn PROP-03 from a convention into a machine-checked structural property, and prove the
first of this phase's three prohibitions (no promotion without explicit human triage).
Output: `packages/core/tests/proposal_no_promotion.rs`.
</objective>
