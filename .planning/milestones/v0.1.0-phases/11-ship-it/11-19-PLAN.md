<objective>
**As** Cyril, **I want to** get a dead project off my board without losing anything, **so that** the
duplicate stuck in `unreachable` stops occupying a rail slot.

D-200: project removal is a reversible soft-hide, never a delete. Deleting a project's board is the
one irreversible act in an application whose core promise is that nothing is lost. The case is
concrete and present, not hypothetical: the live board carries a duplicate registration stuck in
`unreachable` with the same name, the same `THRE` prefix and the same `repo_path` as the active
project, and there is no way out of the surface.

Two data items ride along, because they are about the same live board: D-REV-25's junk lead epic and
D-REV-04's criteria vacuum.

Purpose: implement D-200 and drain D-REV-29, D-REV-25 and D-REV-04.
Output: migration 0022, two core verbs, two commands, a rail action, and two measured data reports.
</objective>
