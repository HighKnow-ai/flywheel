choose when to take it instead of being restarted at.

with the count, and the update does not apply.

|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-17 | Tampering | release-notes rendering | medium | mitigate | Render the notes as React text children only — never `dangerouslySetInnerHTML`, no markdown-to-HTML pass, no anchor built from release content.
