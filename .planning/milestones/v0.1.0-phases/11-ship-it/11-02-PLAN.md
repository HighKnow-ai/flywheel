Write the **unmodified, complete** Apache License 2.0 text to `LICENSE` — all nine sections plus the
"APPENDIX: How to apply the Apache License to your work" boilerplate. Do not paraphrase, do not

Write `NOTICE` with exactly the attribution Apache-2.0 §4(d) makes meaningful: the product name
(`Flywheel`), the copyright line confirmed in Task 1, and one line stating that this product

`flywheel-node` into the bundle, so the shipped artifact carries third-party code and §4 obliges a
notice). No marketing copy — a `NOTICE` file is read by compliance tooling.

source files, and a header sweep is churn that buys nothing a root `LICENSE` does not already buy.
