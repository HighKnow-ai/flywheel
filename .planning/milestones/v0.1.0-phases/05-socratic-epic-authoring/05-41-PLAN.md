<objective>
Gap `G-05-8(a)`: the agent asked its three clarifying questions through the `AskUserQuestion` tool.
The harness captures only `assistant_text`, so the questions never reached
`05-LIVE-CHALLENGE-TRANSCRIPT.md` — the sheet reads *"...three things would materially change the
shape of the spec:"* and jumps straight to *"You didn't pick — no problem."* SHAPE-01 is *"the agent
challenges assumptions and asks clarifying questions"*. The questions ARE the evidence, and the
artefact a human is asked to judge does not contain them.

This is also the stated residual of gap `G-05-7`'s third finding, which `05-UAT.md` marks
`resolved_partially` precisely because closing a universally-quantified truth on two instances is
the overclaim this phase's register exists to prevent. Closing this is what closes that residual;
`G-05-7` is not re-planned.

This plan is the product half: carry the payload through the adapter seam as typed data — the same
remedy plans 05-30, 05-34 and 05-37 used for prior instances of this class — and make the challenge
stage structurally prose-only, so the questions arrive where a human can read them. Plan 05-42 is
the instrument half.

Purpose: an instrument that reconstructs a fact the product already receives fixes the wrong layer.
The wire carries the questions; the seam must too.
Output: a typed question payload on the normalised event, a frozen real capture, and an authoring
tool set that does not contain the form.
</objective>
