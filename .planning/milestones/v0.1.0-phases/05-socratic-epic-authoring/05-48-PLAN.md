<objective>
Change the `propose_*`/`amend_*`/`delete_*` RETURN CONTRACT so staging a proposal hands the agent
back the id of the row the core actually wrote, inside the same tool call.

Implements the write half of D-80 (the session-scoped staging table is the only place a proposal
lives before acceptance, so its row id is the only handle an agent can parent to) across all three
verbs of D-81 (`create`/`amend`/`delete` share one staging shape, hence one shared function and one
contract change). Mirrors D-87's own held read round trip as the reference implementation.

This is the structural fix gap `G-05-10` names, and the item `G-05-9`'s own `missing[0]` named one
round earlier. It is NOT another instruction rewording and NOT another read tool.

Purpose: `propose_criterion` requires `parent_proposal_id`. Today no tool result, and no in-turn
read, can supply one — so the criteria stage is unreachable by construction and SHAPE-03/SHAPE-04
cannot be exercised live.
Output: a held staging round trip carrying the core-minted `proposalId` back to the tool call, a
never-starve discipline on every host failure path, and a regression that fails if the result ever
loses its id again.
</objective>
