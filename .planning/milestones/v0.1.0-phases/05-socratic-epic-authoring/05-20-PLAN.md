<objective>
The live `uat-08` run of 2026-09-24T05:47:26Z finished cleanly and produced nothing judgeable. Its
"Second reply (verbatim)" ends at `Three things would materially change what gets built:` and the
three things — the challenge itself, the only content SHAPE-01's verdict can be rendered from — are
absent from the file.

They were never absent from the wire. `scripts/uat/uat-08-socratic-authoring.mjs:851-868` captures
each "verbatim reply" as ONE `assistant_text` event and writes that one event's `.text` into the
evidence sheet (`:891-892`, `:1017-1018`). One Claude Code turn emits MANY stream-json lines — one
content block each, live-measured against the real binary in this repo at
`scripts/spike/authoring-transport-spike.mjs:114-119` — and
`packages/sidecar/src/claude-code-adapter.ts:586-613` maps each line to exactly one event. The
harness has no concept of a turn. The `result` event that marks a turn's end has been on the wire
since plan 05-02 and is consumed by nothing.

This plan gives the harness the missing noun — **a turn** — and proves it against the real sidecar
for zero tokens.

The decisions at stake are already locked and unchanged here: **D-89** (the challenge stage is free
conversation, turns delivered over the Option A stdin transport) and **D-90** (the human holds the
advance gate). Nothing about either changes. What changes is that the instrument can now tell where
one turn ends — the precondition for honouring D-90 without advancing mid-generation, which plan
05-21 then does.

Purpose: make the transcript a faithful record of what the agent actually said, so SHAPE-01 can be
judged from it at all.
Output: a turn-boundary primitive in the shared harness, a scripted authoring backend that replays
the exact failing shape offline, and a `--replay-check` arm that proves the whole capture path
without spending a credential.

<assumption_delta_decision>
**The noun that is now primary:** *a turn* — one complete unit of agent speech, bounded by the
backend's own `result` line, composed of however many content blocks the model chose to emit.

**Decision: `promote`.**

`uat-08` was written when the harness's only noun was *an event*, so it named the thing it captured
after the thing it could see: `firstReply` is an `assistant_text` EVENT. That singular assumption —
one event is one reply — is false and was always false; the spike measured it false against the real
binary before this script was written.

So the turn becomes primary. `waitForTurn` joins `waitForEvent` in `SidecarClient` as a peer, not as
a wrapper bolted onto one call site: any live script in this directory that wants to know what the
agent SAID (rather than that it said something) asks for a turn. `waitForEvent` is untouched and
keeps every existing caller — `uat-03`, `uat-06`, `uat-07` and both of `uat-08`'s own drain loops
are not edited by this plan.

The promote is enforced rather than intended: Task 1's regression scenario replays the exact shape
that produced the unjudgeable transcript, so a future edit that reverts to one-event capture fails a
command that costs nothing to run.
</assumption_delta_decision>

  <behavior>
    - A chunk that arrived BEFORE the cursor is never part of the turn the cursor opened, even when it is the only `assistant_text` in the buffer.
    - Every chunk that arrived at or after the cursor and before the terminator is present, in arrival order, verbatim, with tool calls interleaved between them not interrupting the accumulation.
