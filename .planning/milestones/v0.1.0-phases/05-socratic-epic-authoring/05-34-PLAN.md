<objective>
Make a non-conversation backend message distinguishable from agent speech by construction, using
the facts the wire already carries about it, rather than by matching the prose of the one message
shape this repository happened to observe first.

This is gap G-05-6's MAJOR finding and the SEVENTH instance of this phase's recurring defect class.
`readBackendRefusal` matches only text whose prefix is the safety-classifier banner, so the live
run's `Not logged in · Please run /login` was counted as the agent's first turn AND as the
distillation reply, the conversation was recorded as having settled after one agent turn, and the
run then waited out the full 120000ms proposal deadline before failing. Plan 05-24 claimed to close
this class; it bound the fix to one message's literal prefix, and the class survived behind the
narrower façade — the same shape as the six rounds of positional-correlation narrowing that plan
05-30 ended by construction.

**The wire already says it, and the adapter drops it.** A real unauthenticated CLI stream, captured
offline at zero cost, puts `"error":"authentication_failed"` and `"is_api_error_message":true` on
the assistant envelope, and `"is_error":true` with `"terminal_reason":"api_error"` on the result
line. `ClaudeStreamMessage` declares none of those fields and `ClaudeStreamResult` declares neither
of its two, so the normaliser cannot read them, so the harness had nothing categorical to classify
on and inferred from prose — and every prose scheme is blind to some ordinary shape.

This is exactly README Item 8's fourth rule: when a verification instrument is reconstructing a
fact the product already receives, the fix belongs at the seam that dropped it. Same rule, same
file, same remedy as plan 05-30's correlation-id carry.

Purpose: end the class rather than narrow it a seventh time.
Output: the wire's own error facts carried through the adapter seam; a categorical classifier that
stops the run at the point of detection; and the real unauthenticated shape frozen as a fixture and
replayed offline as a named scenario.
</objective>
