  `CompactionBoundaryDto` and `DiffSoFarDto`, mirroring the Rust DTOs field-for-field, verified

## Decisions Made

- `ContextPacketDto` (Rust) gained a top-level `decisions: Vec<DecisionDto>` field, mapped from
  `ContextPacket.decisions` — the plan's own Task 1 acceptance criteria required the TypeScript
  mirror to declare `decisions`, but the field did not exist on the desktop DTO before this plan.
- `task_session_summaries`' `SessionSummaryDto.folded` is always `false` — folding is a property
  of the launch sheet's briefing preview (computed once per preview from that packet's own
  compaction boundary), not of the item detail panel's archive view of the same rows.
- `PriorSessionsSection` slices `packet.summaries` by `packet.compaction.foldedCount` rather than
  filtering on each entry's own `.folded` flag, keeping the grouping trivially provable from one
  property.
- `DiffSoFarSection` splits `workingTreePorcelain` on newline and renders raw lines rather than
  parsing porcelain status codes into words — `DiffSoFarDto` carries only raw text, not parsed
  entries, so this section renders the same ground truth the prompt itself carries.
