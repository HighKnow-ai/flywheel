## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → Tauri command surface | Untrusted renderer input crosses into the Rust core; only `project_id` may cross |
| core → system `git` | A branch name and a filesystem path derived from the database reach a subprocess |
| core → SQLite | A new read path over `worktrees`, `tasks`, `epics`, `projects` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08.1-01 | Tampering / Elevation | `commands/change_flags.rs` IPC input | high | mitigate | Only `project_id` is a parameter; branch, base and path are derived inside `packages/core` from the board, mirroring the `review_*` rule. Asserted by a negative grep for path/ref/sha identifiers in the command file. |
