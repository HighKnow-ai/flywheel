<objective>
Close CR-02. 52 sites in `packages/desktop/src-tauri/src/commands/review.rs` (22) and
`packages/desktop/src-tauri/src/commands/forge.rs` (30) map a core error straight to a string with
`e.to_string()`. `git_at` builds its error as the repo path plus the argv plus git's stderr, and
`merge_tree_check` bails with stderr too, so `anyhow::Error::to_string()` hands that verbatim to the
webview — the component that renders agent-produced and repository-supplied content. This violates the
rule both files state in their own headers (T-07-08-01, T-08-08-06): CLI and git stderr is logged, and
only a category crosses IPC. 08-VERIFICATION classes it WARNING; the user chose to include it.

**Goal clause this touches** (ROADMAP Phase 8 goal, clause 3): "and lands it" — the merge and the epic
request are the two commands whose failures a user reads most, and today those failures read as the
user's home path and git's raw complaint.

Output: one shared helper beside the existing `forge_error_code`, applied to all 52 sites, with every
renderer-parsed error string left exactly as it is.

  <action>
    **1. The helper — `packages/desktop/src-tauri/src/commands/mod.rs`.** Add
    `pub(crate) fn ipc_error(context: &str, e: impl std::fmt::Display) -> String`: write
    `eprintln!("{context}: {e:#}")` and return `format!("failed:{context}")`. The generic
    `impl std::fmt::Display` bound is deliberate and is the whole reason this is one helper rather than
    two — it accepts both an `anyhow::Error` and the `PoisonError` from a failed `state.db.lock()`, and
    the `#` alternate flag makes `anyhow` print its full cause chain while `PoisonError` simply ignores
    it. Give it a doc comment stating the rule it enforces (T-07-08-01, T-08-08-06: the raw cause is
    logged, only a category crosses IPC), naming `forge_error_code` as the precedent it generalises,
    and stating that `context` must be a fixed literal — never a path, a branch, a sha or CLI output —
    so the category itself cannot become the leak. Extend the module header with one sentence: every
    handler in these modules maps a core error through this helper.

    **2. Replace all 22 sites in `packages/desktop/src-tauri/src/commands/review.rs`.** Every
    `.map_err(|e| e.to_string())` becomes `.map_err(|e| ipc_error("<context>", e))`. Use a fixed literal
    for `<context>` built as the command name plus the failing step, so the log says which call failed

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tauri command surface -> renderer | The return value of every handler; the renderer is the component that renders agent-produced and repository-supplied content, so anything it receives is potentially reflected |
| git / forge subprocess -> Flywheel | stderr arrives as attacker-influenceable text (a crafted branch or filename reaches it) and is currently forwarded verbatim |
| host process log | Where the raw cause belongs: diagnosable by the developer, not reachable by the webview |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-12-01 | Information disclosure | the 52 error mappings in `commands/review.rs` and `commands/forge.rs` | high | mitigate | `git_at`'s error text carries the repository path, the argv and git's stderr, and `to_string()` forwards it to the webview, leaking the user's home path and repository layout. Every site is routed through `ipc_error`, which logs the chain and returns `failed:<step>`; enforced by a zero-count gate in both files |
| T-08-12-02 | Information disclosure | the category text itself | medium | mitigate | A category built by interpolating a path, branch or sha would move the leak rather than remove it. The helper's contract requires a fixed literal context, checked by inspecting every call's first argument for interpolation |
| T-08-12-03 | Repudiation | the mapped sites' diagnosability | high | mitigate | Replacing a message with a category could make a failure undiagnosable. The helper writes the full `anyhow` cause chain to stderr at every site, enforced by a region-scoped gate on the helper itself |
| T-08-12-04 | Tampering | the renderer-parsed error vocabulary | medium | mitigate | The sheets branch on nine exact prefixes; renaming one silently changes which sentence a user reads. Two loop gates assert all nine survive in their original files, and no TypeScript file is touched |
| T-08-SC | Tampering | npm/pip/cargo installs | n/a | accept | This plan adds no package-manager install task — it adds one function and rewrites existing expressions — so the package-legitimacy gate does not apply and no audit table is required |
</threat_model>
