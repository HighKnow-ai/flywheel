is held by `readiness` reading the widened rows); it is the EXPLANATION that is missing.

**The declare bypass.** `task_file_set_set` reaches `declare_file_set_in_tx`, which replaces a live task's
stored set with no D-152 re-check, and a later widen re-arms the enforcement marker from ALL stored rows —
carrying the unchecked entries into a running agent's scope. The verification names this the most dangerous
of gap 2's three paths precisely because it launders unchecked entries into a live marker.

Purpose: the phase's two promises are "disjointness is a fact" and "you can ask why". A record nobody
writes breaks the second; a write path with no re-check breaks the first.

Output: the widen writes its edge and its event; a declare on a live task is refused and points at the
widen. No migration — the table and its CHECK constraint were built for this in `0019`.
