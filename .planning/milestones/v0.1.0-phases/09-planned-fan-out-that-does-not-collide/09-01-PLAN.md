**2. `packages/core/src/file_set.rs` (new), declared in `packages/core/src/lib.rs`.** The single matcher.
`pub const FILE_SET_FORMS: [&str; 2] = ["file", "dir"];` — the one Rust declaration the migration CHECK
mirrors. `pub enum FileSetEntry { File(String), Dir(String) }`, where the `Dir` variant's string always
ends with `/`. `pub fn parse_entry(raw: &str) -> Result<FileSetEntry, EntryRefusal>` **rejects, never
repairs**: empty or whitespace-only; absolute; any `..` or `.` path segment; a doubled separator; a
backslash, NUL or any control character; any of the five glob metacharacters (asterisk, question mark,
square brackets, braces); a `dir` form naming the repository root; a path under or equal to the git
directory. Each refusal carries a named cause the UI and the planning pass can show verbatim.
`pub fn covers(entry: &FileSetEntry, rel_path: &str, fold_case: bool) -> bool`: a `File` entry covers a
path iff equal; a `Dir` entry covers a path iff the path starts with the directory string **including its
trailing separator**, so `packages/core/src/domain/` does not cover `packages/core/src/domain_x.rs` and
does not cover the directory's own path with the separator stripped. `fold_case` compares
ASCII-lowercased. Pure: no I/O, no connection. Leave `overlaps`/`collisions` to plan 09-03 — this task
needs containment only.

and snake_case serde types `ScopeMarker { version: u32, mode: ScopeMode, worktree_root: String,

**5. `--scope-check` in `packages/shim/src/main.rs`.** A new argv mode checked alongside
`--classify-command` / `--classify-invocation` / `--gate-push`, before the `argv[0]`-stem dispatch:
`--scope-check <marker-path> <absolute-target-path>`. It reads the marker, and prints a single JSON line
to stdout: `{"decision":"unarmed"}` when the marker's mode is unarmed; `{"decision":"allow"}` when the
target, made relative to the marker's canonical worktree root, is covered by some entry;
`{"decision":"deny","entries":[…],"relative":"…","outsideWorktree":true|false}` otherwise. Resolution
order matters: resolve the target's `..` segments, canonicalise its deepest existing ancestor (so a
symlink inside the worktree pointing outside the worktree reads as outside), then strip the canonical
worktree root prefix; a target that does not live under the root is a deny with `outsideWorktree` true.
Exit code 0 for every decision — the decision is the stdout line, not the exit code; exit non-zero only
when the two arguments are absent or the marker path cannot be read, which the hook treats as a deny.
`run_scope_check` must call `flywheel_core::file_set::covers` and must not re-derive containment.

**6. `packages/sidecar/src/scope-hook.ts` (new).** `stage-gate-hook.ts`'s structure, with the one
deviation research measured (M2): that file's bare `main()` means a throw exits 1 and the tool call
**proceeds**. So: install `process.on("uncaughtException")` and `process.on("unhandledRejection")`
handlers, wrap the whole of `main` in try/catch, and attach a `.catch` to the invocation — every one of
those paths prints the deny decision and exits 2. Drain stdin fully before deciding. Resolve
`FLYWHEEL_RUN_ID` and `FLYWHEEL_RUNTIME_DIR` from the hook's own environment only; the payload supplies
nothing but the target path, because a payload is model-adjacent data and must never be able to name
another run's state. Extract the target by tool name: the file tools use `tool_input.file_path`, the
notebook tool uses `tool_input.notebook_path`; a matched tool carrying neither as a non-empty string
denies. Spawn the shim synchronously with `--scope-check <runtimeDir>/scope/<runId>.json <target>` and
branch on the printed decision: unarmed prints `{}` and exits 0; allow prints `{}` and exits 0; anything
else — including a shim that fails to spawn, exits non-zero, or prints an unparseable line — denies. The
deny body is the proven shape: `{"hookSpecificOutput":{"hookEventName":"PreToolUse",
"permissionDecision":"deny","permissionDecisionReason":"FLYWHEEL-SCOPE: …"}}` then `process.exit(2)`. The
reason discloses the refused path made repository-relative plus the declared entries, truncated to the
first 20 with a trailing count of the remainder, and nothing from any other run (resolved discretion #5).

**7. The third `PreToolUse` entry in `packages/sidecar/src/claude-code-adapter.ts`.** Export `const

`execution-hook-settings.test.mjs` with the new entry counts for both branches.
