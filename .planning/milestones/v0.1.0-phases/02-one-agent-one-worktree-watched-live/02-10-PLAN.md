## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → Keychain | A typed secret crosses the renderer, the IPC seam and the Rust core on its way to the Keychain, and must never come back. |
| stored authority → user review | The permission-rules table is the only place a user can see what they have already granted. |
| native menu → action dispatch | A menu item resolves to an action id; the forwarded set is a closed list. |
