<objective>
Make the scanner stop reporting an absence it cannot prove, so the reproduced bypass reaches a
human instead of a shell.

**Phase goal (quoted verbatim from ROADMAP.md):** "Cyril can quit, crash or interrupt Flywheel at
any moment and know that no uncommitted work was destroyed and no agent is still spending his
money."

**Requirement (quoted verbatim from REQUIREMENTS.md):** **AGNT-07** — "Destructive actions
(force-push, branch deletion, recursive delete) always require explicit confirmation, even when the
session is running in an auto-accept permission mode."

**User story:** **As a** developer whose agent is running unattended in auto-accept mode, **I want**
a command that hides `eval` behind an empty quote pair to be refused rather than run, **so that** a
force-push cannot reach my remote without me answering for it.

Purpose: `raw_text_contains_word` matches a keyword as a literal, contiguous substring and performs
no shell word formation. A real POSIX shell resolves `e""val` and `e\val` back to `eval`, and
`g""it` back to `git`, so both conjuncts of the hook's deny rule fall to the same trick,
independently. Because the hidden `eval` redefines `git` as a shell function before any `PATH`
search runs, layer 2 never sees the invocation either — zero human confirmation is reached at any
layer. This plan implements the C1-C4 contract plan 03-29 wrote into the boundary document, and
closes the latent WR-01 composition gap in the same branch.

Output: a scanner whose negative answer is a proof for a class it can name, a hook that cannot
absorb a missing fact into a present one, and a boundary document whose status line is true again.
</objective>
