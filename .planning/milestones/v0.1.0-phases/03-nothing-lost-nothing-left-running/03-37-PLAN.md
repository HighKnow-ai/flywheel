<objective>
Round nine's single remaining gap is a **false claim in a required security artifact**, not a
bypass. `docs/destructive-gate-trust-boundary.md` states C6's charged friction class as a
brace-or-glob-plus-dash token standing at a wrapper's flag position. Measured against the compiled
binary at HEAD, the class C6 actually charges is far broader: an entirely ordinary, non-obfuscated
quoted commit message that mentions a recognised wrapper flag right after `env`/`command` denies too.

**Branch decision, stated up front and carried by this plan: BRANCH (b) — accept the over-trigger
as a deliberate, recorded trade, and correct the claim.** The rationale is in Task 3 and is written
into the document itself; the short form is that branch (a) is not merely expensive, it is unsound:
the nested `sh -c '…'` shapes rounds seven and eight closed reach C6 through the *same*
quote-internal adjacency the false positive uses, so confining adjacency to a token's original
quoted span reopens them. There is no syntactic discriminator between the two.

**MVP user story (derived from ROADMAP Phase 3's `**Goal**` line and Success Criterion 5 — the Goal
line is not in story form and is deliberately not rewritten this late in the phase):** **As** a
developer running an agent in auto-accept permission mode, **I want to** be able to read the gate's
own trust-boundary document and know exactly which of my ordinary commands it will refuse, **so
that** the friction I meet is a price someone wrote down rather than a surprise I have to reverse-
engineer from a refusal.

Purpose: `03-VERIFICATION.md` (round nine, `gaps_found`, 5/6) leaves exactly one truth open, and its
`missing:` item offers exactly two branches. This plan commits to (b), states the true class, records
why (a) was rejected, and asserts the corrected class through the compiled binary — so the next
round inherits a document that matches the code.

Output: a `## Round nine` section recording the falsified claim and the branch decision; a corrected
C6 soundness-class paragraph and friction accounting; a Named-residuals row for the narrowing this
round declines; and four Rust tests pinning the true class, its asymmetry, its boundary, and the
quote-removed form's load-bearing role.
