<objective>
Price round nine's corrected friction class in the corpus, make the shape class mechanically
generable so it cannot go unpriced again, and bind the trust-boundary document to the corpus with a
gate — then leave the next verifier a written coverage map.

This carries the corpus half of the round-nine gap and the structural blind spot the verification
named alongside it: "the friction-pricing discipline currently has no mechanical enforcement for
prose-in-quotes shapes, only for `LAUNCHER_CORPUS`-derived invocations." `obfuscationVariants`
generates its variants from `LAUNCHER_CORPUS.map((row) => row.command)` — real invocations — so it
structurally cannot reach a prose-in-quotes shape no matter how many split kinds it gains. The answer
is a second, sibling generator over prose shapes, plus an invariant tying every friction class the
document claims to a corpus row of that exact shape.

Purpose: this plan exists separately from 03-37, after it, specifically so the document-before-corpus
ordering is a real dependency in the plan graph rather than a comment inside one plan — the same
reason 03-33/03-34 and 03-35/03-36 were split. `## The rule for round six` in
`docs/destructive-gate-trust-boundary.md` is explicit: the document is amended first, and only then
does a row belong in the corpus. In D-62's terms this plan carries item 1 (the checked-in adversarial
corpus, asserted through the real hook against the real shim rather than against the classifier in
isolation) while plan 03-37 carried item 3 (the recorded trust boundary); D-62 item 2's live `claude`
run stands from plan 03-27 and is not re-run here.

**Tracer note.** This round's tracer slice is plan 03-37 Task 1 — the corrected claim and the
plain-prose representative, proven against the compiled binary. Under `TRACER_MODE` one shape leads
one round, so the three tasks here are EXPANSION tasks building out from that proven slice, not a
second tracer. Each is still vertical: each takes a class from asserted-in-one-place to asserted
through the real hook against the real shim, never a layer in isolation.

Output: eight priced corpus rows and one corrected `why`; a prose-shape generator that would have
caught round nine; a document-to-corpus class gate; round-nine structural anchors; and a bookkeeping
record mapping round nine's gap and branch decision to the two plans that closed it.
