# HighKnow's tokens are the source, and Public Sans is the face

Decided by Cyril in [Flywheel takes HighKnow's tokens, face and full-colour mark, and keeps its own dark mode and state colours](https://github.com/HighKnow-ai/flywheel/issues/196) (Epic #189): "I'd like us to reuse the tokens from highknow-mvp where possible (keep the dark mode and additional colours you designed) … TL;DR: you have a nice interface, but I'd like it to be more consistent."

Flywheel ships under the HighKnow mark, so its neutrals, brand text and error now come from HighKnow's own token source: `packages/config/tailwind-preset.css` in `github.com/cymarechal/highknow-mvp`, exported as `packages/config/tokens.json`. A copy of that export was vendored at `docs/design/highknow-tokens.json` (retired on 2026-10-27, see the amendment below), and its `$vendored` block names the repo, the file and the commit it was copied from. `packages/desktop/src/theme/__tests__/brand-tokens.test.ts` holds every borrowed variable in `globals.css` equal to the vendored value. A HighKnow value moves into Flywheel by re-copying the export: the test then fails until `globals.css` follows it. Every variable keeps its shadcn/ui name (ADR 0004), so no component changes.

The UI face changes from **Barlow** (with Barlow Semi Condensed for count and strip labels) to **Public Sans Variable**, HighKnow's face, through `@fontsource-variable/public-sans` 5.3.0. It is still self-hosted and SIL OFL 1.1. One family now carries every role: the condensed role keeps its variable (`--font-ui-condensed`) and its uppercase tracking, but points at Public Sans. JetBrains Mono stays for keys, branches, paths and commands. Public Sans ships a `tnum` feature, so `.tabular-nums` keeps counts and times on tabular figures; the test reads the font file to prove it.

The mark is drawn in its real colours wherever Flywheel shows it (the rail and first-run): the `#3c64dd` tile with the white glyph, fixed in both schemes, as HighKnow's `Wordmark` draws it. The ink-masked silhouette is gone. The mark is identity, not a state colour, so it doesn't count against the brand blue's one meaning.

We rejected two other options:

- **Copy HighKnow's values in by hand, with no vendored source.** The values would drift from HighKnow the first time either side changed, and nothing would say so.
- **Take HighKnow's whole palette, dark included.** HighKnow's dark scales are built for an overlay that sits over a video call and for a reading surface. Flywheel's dark is built around the andon strip and the lamps. Cyril asked to keep Flywheel's dark and its extra colours.

## Consequences

- Kept as Flywheel's own, and absent from the vendored mapping: the grounds (`--background`, `--card`, `--sidebar`, the dark scale), safety yellow (`--attention`), graphite (`--strip`), the lamps, the Diff Tints (ADR 0011), `--subtle-foreground` and the chart neutrals. `docs/design/direction.md` § Tokens lists which variable carries which HighKnow token.
- Where a HighKnow value fails contrast on a Flywheel ground, the hue is kept and the lightness moves the least amount that passes. The deviation is recorded in `direction.md`. None was needed at the commit this ADR was written against: every borrowed value passes on every ground it's drawn on.
- `--ease-out-quint` (`cubic-bezier(0.16, 1, 0.3, 1)`) is the shared easing token. `--ease` stays as an alias, so the screens that use it don't change.
- `--running-border` is new: HighKnow's brand hair on light, and a Flywheel dark sibling in the same hue. It has no consumer yet. It's there for the Stories that follow the design audit (#192).
- Public Sans is wider than Barlow, so a label that fit in Barlow can wrap or truncate. The browser suites and the critique re-shoot are where that shows.

## Amendment, 2026-10-27: the published `@highknow/design` replaces the vendored copy

HighKnow now publishes its design system as an npm package, [`@highknow/design`](https://www.npmjs.com/package/@highknow/design), MIT-licensed and built with npm provenance from the public [`HighKnow-ai/design`](https://github.com/HighKnow-ai/design). Its base is Flywheel's own `globals.css` as it stood on 2026-10-26, value for value, so the tokens this ADR borrowed and the ones Flywheel kept now live in one place that both products read. Flywheel takes the package instead of a copy of HighKnow's export:

- `packages/desktop` depends on `@highknow/design` at one **exact** version from the npm registry (`0.1.0` first), never a range, a git URL or a path. `styles/globals.css` imports its `theme.css`, `base.css` and `fonts.css`, then declares only Flywheel's own roles. The 38 shadcn/ui primitives in `components/ui/`, the duplicated tokens, the base layer, the fonts and the reduced-motion rules are deleted from Flywheel and come from the package.
- **The vendored loop is retired.** `docs/design/highknow-tokens.json` and `theme/__tests__/brand-tokens.test.ts` are deleted: the package is the source, so there is nothing left to re-copy and nothing to hold equal. `theme/__tests__/contrast.test.ts` still owns every contrast floor. It reads the base roles from the installed `theme.css` and Flywheel's roles from `globals.css`, and it fails if `globals.css` declares a base role again.
- **Kept as Flywheel's own**, in `globals.css` after the imports: safety yellow (`attention`, its foreground and wash), graphite (`strip` and its two foregrounds), the `lamp`, the Diff Tints (ADR 0011), the chart greys, `--duration-lamp`, the `--space-*` and radius aliases, the `agent-pulse` loop and the review diff's styles. Button and Badge add the `attention` tone on top of the package's neutral set (`createButton`, `createBadge` in `components/Button.tsx` and `components/Badge.tsx`). A state still picks its tone only in `StateBadge`.
- **Every visible word stays Flywheel's.** The package carries no product copy, so `ReadError`'s line, "Try again" and "Details", the toasts' "Undo", and every label are passed in by Flywheel.
- Flywheel also takes the package's loading rule (nothing for the first 150 ms of a first load, then the skeleton, held at least 400 ms), its `ReadError`, its `Toaster` and `notify`, and its `PageBody` on the one surface that is a centred column (Settings). The package's `TopBar` is not used: Flywheel's header is a breadcrumb trail with Back, Search and the surface's own controls, and `TopBar` is a single title with one action. The andon strip stays Flywheel's.
- A bump is deliberate. Dependabot proposes a new version weekly, in a group of its own, and Flywheel may run a release behind the package on purpose. A release that renames something says so in the package's changelog, and Flywheel moves at the bump that takes it. The 52 px step, Flywheel's lead count, is `text-lead-count` in the package; `lead` there is a 20 px intro step.

We rejected keeping the vendored copy beside the package: two sources of the same values is the drift this ADR set out to stop. We rejected installing the package from a git URL or a local path: the public repository has neither, and only a registry version builds the same everywhere.
